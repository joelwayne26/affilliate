# Joel | Digital Marketing Tools

Professional affiliate marketing website for digital marketing tool reviews, comparisons, and deals.

## Tech Stack
- Next.js 16
- TypeScript
- Tailwind CSS 4
- shadcn/ui

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.
